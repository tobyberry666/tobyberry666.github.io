# Toby — 代码与感受

个人技术主页。静态 HTML、CSS 与 JavaScript，可直接托管于 GitHub Pages。

## 本地预览

需要 Node.js，无需安装依赖：

```sh
node preview.cjs
```

打开 http://127.0.0.1:4173 。若已有预览进程运行，直接打开该地址。

## 验证

```sh
node --test tests/*.test.cjs
node --check app.js
```

GSAP 3.15.0 与 ScrollTrigger 复用现有本机文件，存放于 `assets/vendor/`，保留上游许可说明。原生滚动推进七个横向章节，共享图形、轨迹与背景颜色连续变化；鼠标驱动视差和项目卡片倾斜。底部圆点和顶部导航可直接切换章节，键盘焦点也会带入对应场景。

开启减少动态效果、桌面视口高度小于 620px、手机视口高度小于 520px 或动画库不可用时，采用可正常滚动阅读的布局。后台标签页暂停环境动画，跨手机／桌面布局切换保留探索进度。无需劫持滚轮或强制吸附。

公开内容使用昵称、在读学生身份、编程兴趣、人机交互与情感计算方向和简短奖学金信息；隐去学校与实验室。项目图形为概念示意。旧版图片及识别性介绍已从当前版本移除；旧提交历史不在此次修改范围内。
