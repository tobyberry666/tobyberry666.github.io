# Toby 个人主页视觉升级：已确认设计与实施计划

用户于本群明确选择目标 C「先被个性吸引，再通过作品认可能力」，并回复「先按这版做」，授权按下述设计实施。该授权覆盖本地设计、素材加工、代码、验证和预览交付；不包含向 GitHub 推送、创建公开 PR 或发布上线。

## 目标与架构

将 https://github.com/tobyberry666/tobyberry666.github.io 从柔和彩色的技术主页升级为有编辑设计感的个人交互展览。保留静态 HTML/CSS/JavaScript、仓库内 GSAP 和 ScrollTrigger；保留七章节横向滚动、背景连续变化、鼠标视差、项目卡片倾斜、章节导航和无动画可读降级。无业务后端。

## 设计依据

- 视觉以暖白 #F1EDE5、炭黑 #242321、朱红 #C74432 为基础；允许为对比度和照片协调微调。暖白开场，作品章节可以转入深色，降低原来珊瑚、紫、绿同时出现的密度。
- 首屏为大字 Toby. 与真实人物照片，中文文案「把好奇写成代码。也给生活，留一点即兴。」；保留真实在读学生、编程、HCI 与情感计算信息，不新增履历、学校、奖项、联系方式或虚构成果。
- 展示字体用于大标题，清晰的中文黑体用于正文，等宽字体仅用于编号与技术信息。桌面主标题约140–220px、正文16–18px，使用响应式尺寸，手机独立安排版式。字体优先自托管且有授权；避免加载大体积中文全字库，外部字体失败时仍保持良好排版。
- 用户倒茶照优先用于主视觉：可抠图或摄影裁切、调色。抠图边缘不可靠时使用干净的摄影构图，不强求透明人像，不用生成头像替代本人。面膜照用作可发现的轻量彩蛋，同时支持点击与键盘，不能只有悬停入口。
- 七章：开场、个人介绍、HCI与情感计算、Paper Highlights、Code Visualier、IELTS Graded Vocab、联系。通过人物或统一符号串联，不用人像强占每个作品页。
- 三个项目保留真实外链与现有已知事实，强调问题、特点、体验入口；示意图明确标示，不能假称真实产品截图。
- 保留鼠标视差、卡片倾斜，可增加轻微磁吸按钮反馈；文字与点击目标稳定。彩蛋不依赖音频、滚轮劫持或强制跳转。触屏、键盘与减少动态效果模式仍可访问全部内容。

## 文件职责与实施步骤

### 任务 WEB-01：工程师，本地实现并自验

1. 读取仓库约束、README.md、index.html、styles.css、app.js、preview.cjs 和 tests；检查 git status、分支与最近提交。按适用技能执行隔离与动效工作。在仓库 docs/superpowers/specs/ 保存本设计，在 docs/superpowers/plans/ 保存细化实施计划，自查与本已确认方案一致，不再为重复授权停工。
2. 复制并查看两张照片，制作压缩的展示素材与缩略素材，保留清晰主体。优先可用的本地图片处理工具，不安装大模型或外传照片，不修改用户权限；缺少抠图能力时使用批准的摄影裁切方案。记录尺寸、文件大小、来源与处理方式。建议新建 assets/images/，避免把原始大图直接当首屏唯一资源。
3. 修改 index.html：加入语义化人物主视觉、彩蛋按钮和可关闭照片展示、必要图像尺寸与替代文本，保持七个 section 的现有 id、项目真实链接和导航对应。把大段装饰替换为统一视觉语言，不能仅换颜色后宣称完成。
4. 修改 styles.css：整理色彩/字号/间距变量；实现新的网格、人物构图、作品场景、字体、清晰聚焦样式与移动布局。直接改相关原有规则，避免持续追加冲突覆盖。窄屏与矮屏不能裁掉正文、按钮或人物关键部分。
5. 修改 app.js：保留 GSAP matchMedia、ScrollTrigger 推进、位置恢复和清理逻辑；适配新主视觉的跨章动画。新增彩蛋开关支持 Escape、焦点恢复、触屏；只有确有必要才引入额外文件。新增动态只在精细指针/允许动画时启用，避免与已有 GSAP transform 争用。
6. 先跑原有测试建立基线，修改后运行 node --check app.js、node --test tests/*.test.cjs。增加有价值的交互回归验证，不写只比较 CSS 字符串的空洞测试，不篡改测试以绕过缺陷。
7. 使用可用浏览器自动化或现有工具实际检查 1440×900、390×844、320×568、矮屏桌面和 reduced-motion；覆盖七章滚动、深链导航、项目外链、Tab/Escape、彩蛋和调整视口后的恢复。记录浏览器与检查方式；没有浏览器时如实标注，不能把静态检查当视觉验收。
8. 以 managed background job 启动仓库预览程序（如有可复用进程先核实），记录 job id、端口、准确 URL，验证响应。生成首屏、作品页、手机至少3张截图，保留过程可复查。不能另启 DSH GUI 替代服务器。
9. 更新 README.md，写出实际预览与测试步骤。将变更与素材、设计/计划文档本地提交（有身份配置时），不要 push、发布或创建公开 PR。交接工程绝对路径、分支/commit、diff摘要、原始命令输出、截图路径、预览URL和job id、已知限制给 Chief。

### 任务 WEB-02：审校官，独立验收

依赖 WEB-01 交接结果。独立读取代码、diff、截图并访问实际预览或自行运行可用验证，不把工程师结论直接当证据。核对设计实现、照片与真实信息、七章交互、桌面/移动布局、键盘与减少动态效果、资源和字体。输出 PASS / REWORK / BLOCKED，问题附定位与证据。需要返工时仅交给工程师，最多两轮。
